# 仓库文件管理

提交源码、测试、项目依赖、`configs/` 示例配置、`docs/` 技术文档、
`progress.md` 和 `baseDocs/` 项目参考资料。

`.gitignore` 排除虚拟环境、Python 缓存、构建产物、测试报告、本机编辑器
状态、系统杂项、运行日志、`data/` 实验数据与 `outputs/` 生成结果。
本地 `.env` 及其变体不提交；不含密钥的 `.env.example` 和 `.env.template`
可以提交。真实视频、标定文件和实验记录放在 `data/`，避免混入源码目录。

忽略规则不按 CSV、JSON、PNG、PDF 或 Word 等文件后缀一律排除，
因此配置、测试样本和项目参考资料仍可正常版本管理。

检查某个文件为何被忽略可执行 `git check-ignore -v <路径>`。
已被 Git 跟踪的文件不受新增忽略规则影响，需要用
`git rm --cached <路径>` 移出索引；这会保留本地文件。
本轮已将 `.idea/` 的本机配置移出索引，下一次提交会记录这些路径的删除。
忽略规则和索引移除不会清除远端已有的历史提交。

# S1 三维运动计算方法

所有输入均按单鱼轨迹处理，帧号与时间戳严格递增，单位及坐标系一致。
仅对连续帧且坐标有效的相邻点计算位移矢量 `P_i-P_(i-1)` 和步长
`||P_i-P_(i-1)||`；累计路径长度
是这些有效步长的和。缺失点或跳帧处不跨越连接路径。

内部点的速度矢量按中心差分计算：

`V_i=(P_(i+1)-P_(i-1))/(t_(i+1)-t_(i-1))`。

速度大小为三维范数 `||V_i||`；方向向量为端点位移的单位向量。
当端点位移不超过配置的 `min_direction_displacement` 时，方向无定义。
首尾点没有中心差分值。

转向角取相邻三点的入向位移 `u=P_i-P_(i-1)` 和出向位移
`w=P_(i+1)-P_i` 之间的夹角 `acos(clip(u·w/(||u||||w||),-1,1))`。
任一位移不超过配置阈值时，角度和角速度记为 NaN。按照项目任务书，
角速度模为该夹角除以外侧两点的时间跨度 `t_(i+1)-t_(i-1)`，单位 rad/s。
这一定义用于本阶段复现；对匀速圆周轨迹，它给出几何角速率的一半，
与以相邻线段中点时间差为分母的定义不同。真实行为阈值使用前须统一口径。

速度及转向角对噪声敏感；本阶段仅提供最小位移阈值以屏蔽近零向量，
没有真实鱼轨迹的滤波或误差校准。所有示例数据和图表均标记 synthetic。

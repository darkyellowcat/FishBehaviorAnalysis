# S3 LBAdaptiveSOM 复现说明

本实现以 `baseDocs/基于3D计算机视觉的鱼类行为分析研究.pdf` 第 251--252 页
式(2)--(5)及图(4)、图(5)为依据，使用 NumPy 独立实现。
算法版本为 `paper2015_hsv_squared_v1`。本轮按用户最初确认的阶段表完成背景
建模与前景分割，质心提取在 S4；任务书将质心并入 S3 的编号差异据此处理。

## 数据和模型

`LBAdaptiveSOM.segment(ViewFrame)` 接受 S2 输出的 uint8 HSV ROI，并返回
带同帧时间戳、视角与 ROI 原点的 `ForegroundMask`。掩膜为 0/255；背景与
阴影均为 0。每个视角使用独立模型，不在镜像与实体 ROI 之间传播模型更新。
输入视角、ROI 原点及尺寸须保持一致；帧号和时间戳严格递增。

将 OpenCV H×2 转为角度，S/V 除以 255 转为 0..1。模型保存浮点
`(H_deg, S, V)` 权重，形状为 `(height*n, width*n, 3)`；每个输入像素
对应连续的 n×n 模型块。初始化将第一帧各像素复制到其 n² 个节点。

## 公式及明确的实施口径

- 特征映射为 `(V*S*cos(H), V*S*sin(H), V)`；计算余弦前将 H 转为弧度。
  距离采用两个特征之差的平方和。论文文字称“欧式距离”，但式(2)印有
  范数平方，本版遵从印刷公式；epsilon 的尺度也是平方距离，不能直接当作
  未平方的距离阈值使用。
- 每个像素寻找其模型块中的最小距离节点，式(3)的 `d <= epsilon` 判为
  背景并更新。文字中的“小于”与公式中的“不大于”不完全一致，本版遵从公式。
- 最小距离超阈值后，按式(4)判断阴影：gamma <= V/V_ref <= beta、
  S-S_ref <= tau_S、abs(H-H_ref) <= tau_H。保留单侧饱和度差和线性色相差；
  不擅自改成绝对饱和度差或环形色相差。论文未写 tau_H 的单位，本版明确使用度。
  参考亮度为 0 时比值无定义，不归入阴影；相同黑色已由距离匹配处理。
- 背景匹配触发式(5)的线性 HSV 权重更新：
  `A <- A + learning_rate * exp(-(dy²+dx²)/(2*sigma²)) * (pixel-A)`。
  高斯峰值为 1，不归一化为和等于 1；邻域以最佳节点为中心，半径 `n//2`，
  可跨越相邻输入像素的模型块，超出模型边界时裁剪。论文的 n/2 索引对 n=3
  产生半整数，本版按图(5)的九节点解释为整数半径 1。
- 论文没有指定同帧重叠邻域的更新顺序。实现按输入像素从上到下、从左到右
  原位更新；并列最小距离取模型块中同样顺序的首个节点，保证可重复。
  前景与阴影像素不主动触发更新，附近背景像素的邻域更新仍可能影响对应节点。

## 参数来源

| 参数 | synthetic 示例 | 来源及含义 |
|---|---:|---|
| mapping_size | 3 | 论文 n=3 |
| learning_frames | 3 | 工程设定；含初始化帧，相当于论文 K=2，t=0..2 |
| epsilon_learning / epsilon_online | 0.1 / 0.01 | 从论文 epsilon1 范围及 epsilon2≈0.1*epsilon1 选取 |
| learning_rate | 0.05 | 论文只说明常数，数值为本版工程设定 |
| gaussian_sigma | 1.0 | 论文未给具体值，数值为本版工程设定 |
| shadow_gamma / shadow_beta | 0.7 / 1.0 | 论文阴影亮度比示例 |
| shadow_saturation_tolerance | 0.1 | 论文示例，配合归一化 S |
| shadow_hue_tolerance_deg | 10.0 | 论文 tau_H=10，本版明确采用角度单位 |

第一帧初始化输出空掩膜；随后使用学习阈值，达到 `learning_frames` 后切换
在线阈值。学习阶段仍执行同样的背景、阴影与前景判定，未强制将所有像素
吸收为背景。配置集中在 `configs/synthetic_som.yaml`。

S3 演示视频采用 `synthetic_video.background_only_frames=3`，先给出三帧无鱼
背景，再出现两个运动椭圆。这是测试数据设计，并未改变第一帧初始化算法。
S2 生成器该选项默认为 0，原有 S2 示例仍在第一帧绘制合成鱼。

## 输出、验证与限制

`som-demo` 生成视频后处理；`segment-video` 处理已有视频。输出为
`masks/mirror/`、`masks/real/`、`masks/full/` 的二值 PNG、`overlays/` 的叠加 PNG，
`segmentation.csv` 的逐帧双视角阶段/阈值/前景与阴影计数，以及两个
`background_model_<view>.npz` 状态文件。NPZ 包含完整 HSV 权重与 JSON 元数据，
可用 `np.load(..., allow_pickle=False)` 检查；本阶段未提供模型恢复续跑接口。
运行记录保存输入及配置 SHA-256、配置快照、算法和依赖版本、标定状态及耗时。
示例 CSV、模型元数据及运行记录均标记 `synthetic`，视频和叠加图保留标识。

单元测试验证平方距离与色相周期、初始化、两阶段阈值、前景/阴影不触发更新、
高斯更新数值、跨块更新及边界、首帧含鱼的局限；另用 synthetic 视频检查
二值掩膜、ROI 拼接、CSV 及模型保存。

第一帧中已有的鱼会成为初始背景，此限制有专门测试。匹配距离保留了色相
周期性，但式(5)直接平均 HSV 会在色相跨越 0/360 度时引入错误中间色；
阴影的线性色相差也有边界问题。本版保留这些基线行为并明确记录，尚未加入
环形更新等工程改进。Python 顺序实现未承诺论文环境中的实时性能。
尚无真实鱼视频、光照及标定条件的验证；参数需要真实样本评估，不能据此
声称实验分割准确率。形态学处理、质心、跟踪与三维重建留待后续阶段。

# 0. 使用说明与来源界限

本任务书用于你与实验人员进行数据对接，并作为 Codex 分阶段编写、测试和迭代 Python 代码的统一需求依据。它不是对原论文和对方规划书的简单拼接，而是按“数据采集—算法处理—验证交付”重新组织。

- 【论文依据】表示原论文直接描述的方法、公式或论文实验设置。
- 【规划书依据】表示实验方在18页《复现方法及设计》中提出的数据或操作要求。
- 【工程设计】表示为了可运行、可测试、可交付而增加的接口、质量控制、开发组织，不应视为论文原文。
- 【待确认】表示必须向实验负责人核实，或需通过真实视频和标定数据验证的内容。

> **注意：** 论文中的45°、640×480、左右285/355分区以及行为阈值均为论文或规划书给出的示例实验设置，不自动构成新实验的真实测量结果。

# 1. 项目目标、范围与最终成果

目标：利用单摄像机同时拍摄鱼本体与平面镜反射像，经前景分割和质心定位，估计鱼的三维质心轨迹，计算速度、角速度及行为指标，并输出可追溯的数据、图表和视频结果。【论文依据：第250—255页；规划书依据：第1、14—18页】

范围：你仅负责软件与算法；不承担鱼缸、摄像机、镜面搭建、活体实验、设备操作或实际视频采集。你需要定义算法所依赖的数据格式并向实验方提出明确的交付要求。

| 最终交付物 | 最低要求 |
|---|---|
| 可运行源码 | Python项目、配置文件、依赖清单、入口脚本、README |
| 视频/图像处理 | 去畸变接口、中值滤波、HSV转换、双视角ROI处理 |
| 视觉算法 | LBAdaptiveSOM、目标区域/质心、单目标跟踪、双视角匹配 |
| 几何与运动分析 | 三维计算、轨迹、速度、角速度、无效帧标记 |
| 行为与展示 | 规则识别、行为事件表、标注视频、3D轨迹图、运动曲线 |
| 验证与文档 | 模拟测试、单元测试、真实视频验证记录、局限性说明 |

# 3. 从原始视频到结果的算法主链

原论文处理顺序：背景建模 → 前景检测 → 质心提取 → 空间位置计算 → 游动速度及角速度 → 行为描述。【论文依据：第251页图3】

工程上的完整流水线（增加数据校验、双视角ROI、时间管理、结果追溯）：

```text
原始视频 + 元数据 + 标定文件 + 镜面几何配置
             ↓
帧读取/去畸变/中值滤波/HSV转换
             ↓
实体鱼ROI、镜像ROI  →  LBAdaptiveSOM前景掩膜
             ↓
连通域与质心计算 → 单目标时序跟踪 → 双视角对应
             ↓
几何坐标转换与3D质心估计（含有效性/单位）
             ↓
3D轨迹 → 速度/角速度 → 行为规则 → CSV/图片/标注视频
```

# 4. 模块级详细需求

## 4.1 M0：工程与数据接口（首先完成）

输入：配置文件、实验数据交付规范。输出：可执行工程框架、数据结构、验证工具。

- 统一 frame_id、timestamp_s、fps、view（real/mirror）、坐标方向、单位和缺失值策略。
- 所有计算结果写明数据来源、算法版本、配置快照，原始视频只读保存。
- 参数不得散落硬编码：ROI、alpha、split_x、阈值、滤波核、背景学习轮数等进入 YAML 配置。
## 4.2 M1：轨迹数学与模拟测试

输入：带时间戳和有效性标记的二维/三维坐标；输出：逐帧运动数据、轨迹图、速度图、角速度图。

建议的中心差分速率：v_i = ||P_(i+1) - P_(i-1)|| / (t_(i+1) - t_(i-1))。这是中心时间窗口内的端点位移速率近似；累计路程应另按逐段路径求和。【工程设计：显式统一时间定义】

方向变化角：u = P_i - P_(i-1)；w = P_(i+1) - P_i；Δφ = arccos(clip((u·w) / (||u||·||w||), -1, 1))；角速度模 = Δφ / (t_(i+1)-t_(i-1))。若向量长度过小、缺帧或时间戳无效，则该指标标记为无效。

必须测试：静止（速度0，方向角不可定义）、匀速直线、拐弯、缺失点、重复时间戳、像素与毫米单位。数据若无物理标定，只能报告 px/s 或 pN/s，不可写成 mm/s。

## 4.3 M2：视频预处理与区域配置

【规划书依据：第6—8页】读取每帧；进行相机去畸变、中值滤波、HSV转换，并可保存过程图像。论文描述先进行中值滤波用于实验比较。【论文依据：第253页】

- 优先用原始帧配置或校验左右视角ROI，再把区域分割和质心结果映射回全帧坐标。
- 论文/规划书示例分辨率640×480、左侧285像素和右侧355像素；实际位置必须从实验画面确认。
- 保存或计算帧号到时间戳映射；若无法获取独立时间戳，才用 frame_id/fps 计算近似时间。
## 4.4 M3：LBAdaptiveSOM前景分割（论文核心复现）

【论文依据：第251—252页式(2)—(5)；规划书依据：第9—13页】背景模型3×3映射（n=3）、HSV特征、初始化/学习阶段与在线阶段、最小距离判别、阴影判断、邻域加权更新。

- 模块输入：HSV帧、模型状态、阈值参数；输出：每帧二值前景掩膜、可选背景状态/诊断图。
- 必须显式处理OpenCV H/S/V数值范围及归一化，保留论文中的色相周期性表示；阈值与数值范围必须配套。
- 第一帧用于初始化是论文设定；鱼在第一帧出现时可能进入背景，应记录并测试，必要时提供独立的工程改进选项。
- 原论文给出ε1∈[0.05,0.2]、ε2约为ε1的10⁻¹倍、γ=0.7、β=1.0、τS=0.1、τH=10等示例；K、学习率及权重细节仍需实现中记录配置。
对比方法如MOG2/KNN可以作为基线，但不得未经说明替代LBAdaptiveSOM作为“论文复现结果”。

## 4.5 M4：质心提取、时间跟踪、双视角匹配

输入：实体视角与镜像视角的前景二值图；输出：每帧两个视角的检测质心、有效性标记和关联结果。

- 对每个区域进行阈值/形态学清理、连通域筛选，使用前景像素均值得到质心：xc=Σxk/N，yc=Σyk/N。N=0则返回缺失，不能返回(0,0)。
- 优先按规划书先用1条鱼测试；先做单目标关联，再依据真实鱼数量决定是否需多目标跟踪和身份管理。
- 左右ROI的局部坐标须转换为一致的全帧坐标；鱼本体与镜像必须在同一时间戳对应。
## 4.6 M5：单摄像机+平面镜三维几何

【论文依据：第250—251页图1、图2及式(1)】根据成像装置几何关系，以两个视角的鱼质心作为匹配点估计三维坐标。论文给出 z = z′ = (a - x′)tanα，α=45°。

【规划书依据：第14—15页】写出示例简式 X=x、Y=y、Z=285−x′（单位pN）。这反映规划书采用论文像素尺度/理想模型的复现路线，不等于在任何真实实验中得到物理毫米坐标。

- 软件必须分离：像素坐标、校正后像素坐标、几何模型坐标和物理世界坐标；每种结果随字段标注 coordinate_frame 和 unit。
- 对方至少提供相机内参/畸变、镜面夹角、镜面位置、实际空间尺度、视频视角/ROI；若要报告物理3D尺度，还需建立可验证的像素到物理坐标映射。
- 玻璃/水界面折射可能产生偏差；如未建模或未验证，应明确标为几何简化模型结果。
- 先以理想模型和已知三维点进行逆向一致性单元测试，再用实际标定与参考点进行验证。
## 4.7 M6：行为识别、结果展示与评估

【论文依据：第253页表1】论文讨论：跳出水面（z>h）、在水面持续漂浮（z=h且持续>15s）、狂游（速度>阈值或角速度>阈值）。论文给出h=182、v阈值45、角速度阈值1.7等特定实验条件数据。

- 规则作为可配置策略；实际结果不能把“z==h”直接浮点精确比较，需设置高度容差和时间窗口。
- 自动预测标签需与人工参考标签区分；规划书仅列出行为标签数据要求，未定义其独立真值标注流程，需与实验人员补充确认。
- 输出：带检测/质心/轨迹的MP4、foreground PNG、逐帧CSV、3D轨迹PNG、速度与角速度曲线PNG、事件CSV。
- 性能评估：若具有人为标注，可计算分割IoU/Precision/Recall、质心误差、轨迹中断率、事件级查准/查全等；无人工真值不能声称识别准确率。
